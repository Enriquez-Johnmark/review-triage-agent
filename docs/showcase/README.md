# Showcase

Screenshots and a captioned walkthrough of the dashboard on the made-up demo (`pnpm cli load-demo`): 120 invented reviews of a fictional finance app, `com.example.wallet`, sorted by Claude (its recorded answers), with a crash spike in version 4.2.0 this week. Made on 2026-11-08 with the owner's API key: Claude drafted every reply shown live, and the same rules checked it.

## Making them again

Playwright scripts in `web/showcase/` make them against the real server, which starts on a fresh demo database. Claude drafts live, so they need the API key in `.env` (in a cloud session, `OWNER_ANTHROPIC_API_KEY`); the video needs `ffmpeg`.

```sh
pnpm --dir web build
pnpm --dir web showcase
```
